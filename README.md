# Diabetes-Prediction

# 💉 Diabetes Prediction Web App

Welcome to the **Diabetes Prediction App** — a powerful and user-friendly machine learning tool that helps users assess their risk of diabetes based on common medical inputs.

🔗 **Live App**: [Click to Visit the Diabetes Prediction App](https://diabetes-prediction-fqnnp6xjqljf9w75bjh6t2.streamlit.app/)

---

## 🚀 Features

- 🔬 Predicts diabetes risk using a trained Support Vector Machine (SVM) model
- 🧠 Takes real-world medical inputs like glucose, blood pressure, BMI, etc.
- 📊 Generates a risk chart and provides personalized health advice
- ❄️ Beautiful animations (balloons or snow) based on prediction outcome
- 📄 One-click download of a personalized PDF report
- 🎨 Stylish and responsive Streamlit UI with background image
- 📝 Expandable section to view all input values

---

## 🧠 Model Overview

- **Model Used**: Support Vector Machine (SVM)
- **Dataset**: PIMA Indian Diabetes Dataset (Kaggle)
- **Preprocessing**: StandardScaler applied for normalization
- **Frameworks**: Scikit-learn, Streamlit, Joblib, FPDF
